# pvault [![Build and Test](https://github.com/binarysoupdev/pvault/actions/workflows/build.yml/badge.svg?branch=main)](https://github.com/binarysoupdev/pvault/actions/workflows/build.yml)

Simple and secure JSON-based password manager.

## Releases

- [`v2.0.0`](https://github.com/binarysoupdev/pvault/releases/tag/v2.0.0) | Fully featured, fully unit-tested!
- [`v1.0.0`](https://github.com/binarysoupdev/pvault/releases/tag/v1.0-beta1) | (Legacy) Clunky code-base, no unit tests.

## Commands

| Command | Usage |
|---|---|
| `config`  | Configure the application |
| `vault`   | Configure the vault |
| `pass`    | Generate a new random password |
| `search`  | Search records in the vault |
| `create`  | Create a new vault record |
| `lock`    | Lock a record in the vault |
| `unlock`  | Unlock a record from the vault |
| `delete`  | Delete a record from the vault |
| `copy`    | Copy password/username of a record |
